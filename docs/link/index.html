Download OpenAPI specification:

Servicios de consulta y validación de kiban (CURP, SAT, IMSS, Buró, etc.) y administración de credenciales. En sandbox (sandbox.link.kiban.com) las ejecuciones responden test cases en lugar de llamar al proveedor.

Ejecutar un servicio de link

Ejecuta un servicio del catálogo de link (p. ej. curp/validate, sat/rfc_validate_pf, imss/nss). El servicio y la operación van en la ruta; el body depende de cada servicio. Responde el detalle de la ejecución, también cuando el proveedor falla (408/503/406 traen el detalle con su error). Los subservicios de auditoría responden un CSV.

Authorizations:
ApiKeyAuth
path Parameters
service
required
string

Servicio del catálogo (p. ej. curp, sat, imss, bc_pf)

subservice
required
string

Operación del servicio (p. ej. validate, query)

query Parameters
sandbox
boolean

Modo sandbox. Tiene que coincidir con el modo de la API key: una key de sandbox exige sandbox=true y una de producción no lo acepta. Se ignora en el host sandbox, donde ya es implícito

testCase
string

Sandbox: nombre del test case que debe responder

testCaseId
string

Sandbox: id del test case que debe responder

header Parameters
origin
string

Identificador libre del origen de la petición

Request Body schema: application/json
required

Datos del servicio; cada servicio define sus campos

object

Responses

Crear una credencial

Guarda una credencial (vault) para usarla después en los servicios que la piden. El tipo sale del catálogo de tipos de credencial y define qué campos lleva el body; por ejemplo {"name": "buro-pf", "type": "BC_PF", "usuario": "…", "password": "…"}. Los secretos nunca se devuelven.

Authorizations:
ApiKeyAuth
query Parameters
sandbox
boolean

Modo sandbox. Tiene que coincidir con el modo de la API key: una key de sandbox exige sandbox=true y una de producción no lo acepta. Se ignora en el host sandbox, donde ya es implícito

Request Body schema: application/json
required

Objeto con name, type y los campos propios del tipo de credencial (cada tipo define los suyos; por ejemplo BC_PF: usuario, password y autorenew opcional). Los secretos nunca se devuelven

object
